# kvcrawl

A collection of standalone systems projects living in a single repository.

This repository contains:

* **[Simple KV Store over RPC](kv/README.md)** — a lightweight key-value store accessible through RPC.
* **[Web Crawler](web-crawler/README.md)** — a concurrent crawler for fetching pages and extracting links.

Each project is independent and can be built, tested, and run separately.
